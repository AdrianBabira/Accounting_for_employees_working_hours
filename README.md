# Учёт рабочего времени сотрудников

Небольшое веб-приложение на Django и SQLite для списка сотрудников, таймеров задач и отчётов о затраченном времени. Интерфейс на русском языке; авторизации нет. В проекте не используются реальные данные.

## Запуск

Нужен Python 3.10 или новее.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Откройте <http://127.0.0.1:8000/>. На главной странице можно добавить сотрудника, запустить таймер с описанием задачи и остановить его. Ссылка «Отчёт за период» показывает записи и суммарное время по выбранным датам, для всех сотрудников или одного сотрудника. В отчёт попадает часть записи, пересекающаяся с периодом; активный таймер учитывается до текущего времени. Данные хранятся в `db.sqlite3` и остаются после перезапуска сервера.

Запуск проверок:

```bash
python manage.py test tracker
python manage.py check
```

## Ошибки, найденные и исправленные при разработке

- Первые POST-тесты выявили, что сообщения Django использовались без подключения приложения и middleware сообщений/сессий. Они добавлены в настройки; после этого тесты проходят.
- Повторная отправка старта могла бы создать несколько активных таймеров. Добавлено ограничение уникальности в SQLite для активной записи сотрудника; интерфейс сообщает, если таймер уже запущен.
- Поле начала записи изначально было помечено `auto_now_add`, что мешает задавать явное время и проверять отчётные интервалы. Используется `default=timezone.now`, поэтому возможны как обычный запуск с текущим временем, так и точные тестовые даты.

Все имена и описания в примерах — вымышленные.
